# Review checklist

- [ ] I can explain what this change does and why
- [ ] It stays inside the task slice
- [ ] Tests assert the acceptance criteria, not just current behavior
- [ ] No new dependency, or each one is verified and justified
- [ ] No secrets, real personal data or credentials
- [ ] Input validation, authorization and error handling checked
- [ ] Irreversible or external actions require approval
- [ ] Logs do not leak sensitive data
- [ ] The diff is small enough to review honestly
- [ ] Known limitations are documented
