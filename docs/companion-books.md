# Companion code for the books

Two books on leading AI adoption, and the repositories that put their ideas to the test. The books give the leadership view; the code tests it with synthetic data and declared limits.

## Education

**[Leading with AI: Embracing the Future of Education](https://www.amazon.fr/dp/B0CN5PG7LT)**

| Repository | What it tests | Case study |
|---|---|---|
| [ClassMind](https://github.com/yassineaqejjaj/ClassMind) | Teacher-reviewed learning analytics and AI-supported exercises | [Case study](case-studies/classmind.md) |
| [SimuLearn](https://github.com/yassineaqejjaj/SimuLearn) | Simulation-based practice with cited feedback | [Case study](case-studies/simulearn.md) |
| [TRAIL Academy](https://github.com/yassineaqejjaj/TRAIL-Academy) | An AI learning platform with assessments | [Case study](case-studies/trail-academy.md) |

## How it connects to the framework

The framework's caps apply directly to these domains: sensitive data and irreversible actions stay at **autonomy L1 at most**, data is synthetic, and consequential actions need human approval. See [autonomy levels](autonomy-levels.md).

All projects are prototypes or MVPs. None is a certified medical device or an approved system for patient or student data.
